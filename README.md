# Common Value Auctions with Fully Informed and Fully Uninformed Participants
## Overview

In a common value auction, the object has the same value for every bidder, but each bidder holds only partial information about that value. Bidders who ignore this risk the winner's curse: conditional on winning, the bidder's estimate of the value was likely too high.

This paper studies a common value setting with extreme informational asymmetry: some participants are fully informed about the value of the object, while the others are fully uninformed and know only the prior distribution. We analyze optimal behavior and outcomes in this environment and connect the result to the classical literature on information structure in auctions.

### Research question: 
What mechanism structure maximizes the seller’s expected profit in a common value auction with fully informed and fully uninformed participants, where each participant receives information about the true value of the good with equal probability?
### Approach 
#### Model:
Common value auction with two types of participants (fully informed and fully uninformed)
#### Optimization: 
The problem is formulated as a linear program, and the solution is characterized through the Karush-Kuhn-Tucker (KKT) conditions. 
#### Literature: 
The analysis builds on the work of Milgrom and Weber (1982) on auctions with affiliated signals, and on Cremer and McLean (1985, 1988) on surplus extraction when bidders' information is correlated.
